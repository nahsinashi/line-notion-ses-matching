# SESマッチングシステム統合改修計画

**作成日: 2026-03-30**
**最終更新: 2026-03-31**
**最終更新: 2026-04-07**
**ステータス: Phase 1-3 完了、Phase 4 未着手**

---

## 背景・目的

- 現在、案件/要員情報の入力経路が複数あり（LINE自動、Googleフォーム手動）、処理ロジックも分散している
- LINE経由のAI処理（Gemini/Claude API）に従量課金が発生している
- Googleフォームでの手動登録は自分の運用では使わない
- メール経由の情報も今後自動で取り込みたい

**目標: 全入力経路を統合し、AI処理をClaude Code（サブスク）に集約する**

## 現行システム（変更前）

```
パートナー → LINE送信 → GAS webhook → AI分類（Gemini/Claude API ※課金）
  → Notion登録 → AI整形（Gemini ※課金）→ マッチング（Gemini ※課金）
  → LINE通知（パートナー向け）

手動 → Googleフォーム → GAS → Notion登録 → AI整形 → マッチング
```

### 廃止するもの

| 項目 | 理由 |
|------|------|
| GASのAI分類・整形・マッチング | Claude Codeに集約（API課金削減） |
| Googleフォーム（自分の運用） | 自動化で不要に（メンバー向けは残す） |
| パートナー向けLINE通知 | 実運用なし。打診・提案の返信に置き換え |
| 管理者承認フロー | 不要 |

## 提案フロー（候補以降）

```
候補（自動生成 — マッチングスコア70+）
  ↓ ユーザーがNotionでステータスを「打診中」に変更
打診中
  ↓ Claude Code 定期実行で検知
  ↓ → 要員元へ打診文を自動生成
  ↓ → LINE: gas-inbox経由で自動送信 / メール: 文面生成のみ（手動送信）
  ↓
  ↓ 要員元がLINEで返答 → Inboxに入る
  ↓ → Claude Codeが「打診への返答」と自動検知
  ↓ → OK/NG をAI判定
  ↓
  ↓ OKの場合 → ステータスを「提案中」に自動変更
  ↓   → 案件元へ提案文を自動生成・送信
  ↓ NGの場合 → ステータスを「見送り」に自動変更
  ↓
提案中 → 面談 → 結果待ち → 決定 / 見送り / 辞退
```

### 送信手段

| 入力経路 | 打診・提案の送信方法 |
|---------|-------------------|
| LINE | gas-inbox 02_SendMessage.gs 経由で自動送信（Push Message API） |
| メール | 文面を自動生成。送信は手動（セキュリティ上の制約） |

## GAS構成

### gas-inbox（新規作成・デプロイ済み）

| ファイル | 役割 | 方向 |
|---------|------|------|
| 00_Config.gs | スクリプトプロパティ管理 | — |
| 01_Webhook.gs | LINE受信 → Inbox書き込み + action振り分け | 受信 |
| 02_SendMessage.gs | LINE送信（Push Message API）/ メール文面生成 | 送信 |

**doPostの振り分け:**
```
POST リクエスト受信
  ├─ body.action === "send"  → 送信処理（02_SendMessage.gs）
  └─ body.events あり        → LINE受信処理（01_Webhook.gs）
```

**スクリプトプロパティ:**
- `LINE_CHANNEL_ACCESS_TOKEN`
- `NOTION_API_KEY`
- `INBOX_DB_ID`: `0bdab766b9554d858607a4e078ede167`
- `SKILLSHEET_FOLDER_ID`

### gas-admin（既存 → 停止）

LINE DevelopersのwebhookURLをgas-inboxに変更済み。gas-adminには今後webhookが届かない。

### gas-main（既存 → メンバー向けに維持）

Googleフォームパスはメンバーが使用中。変更なし。

## 制約・方針

| 項目 | 方針 |
|------|------|
| AI処理コスト | Claude Code サブスクリプション内で完結。従量課金API不使用 |
| 既存メンバー向けシステム | Googleフォームパス（gas-main）はそのまま残す |
| リアルタイム性 | 15〜30分の遅延を許容 |
| LINE送信 | gas-inbox経由で自動送信 |
| メール送信 | 文面生成のみ。自動送信はしない（セキュリティ上の制約） |
| 棚卸し | 1-2週間経過の案件/要員を自動クローズ |
| 既存データ | 移行要否は別途判断 |
